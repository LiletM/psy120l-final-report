# psy120l-final-report

# Experiences in Long-Distance Romantic Relationships 

## Overview 

This repository contains the published HTML version of my PSY 120L final reproducible report. 

This project examined how communication responsiveness in long-distance romantic relationships affects relationship satisfaction in various attachment styles and prior relationship experience. 

## Report

The published report is available through GitHub Pages. 

## Tools 

The report was created using Quarto and R. 

## Files

This repository includes: 

- 'index.html': The published HTML version of the reproducible report
- 'README.md': A brief description of the repository

## Note

The data set is not included in this repository. Only the rendered HTML report is published.
